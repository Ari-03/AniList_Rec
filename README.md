# AniList Recommender

An exportable anime recommendation model: connect an AniList account, get ranked recommendations for anime you haven't seen. Developed in Python + marimo; a public web app will later consume the exported model.

Planning for this effort lives on the [wayfinder map](https://github.com/Ari-03/AniList_Rec/issues/1) — its sub-issues are the open decisions. Research findings land on `research/<name>` branches, linked from their tickets.
